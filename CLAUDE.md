# Maranza Simulator

Satirical 2D browser life-sim (PWA, mobile-first) developed by the Casa Bombadil collective.
Game language: Italian. Code and comments: English or Italian, consistently within a file.

## Project map
- `docs/GDD.md` — the game design document. Source of truth for rules and UI. Lines starting with `$`
  are internal designer notes: follow them, never surface them in game text.
- `data/game-data.json` — every balancing number (classes, actions, shop, courts, events, constants).
  Generated by `sim/export_data.py`; never edit by hand and never duplicate its values in code.
- `sim/maranza_sim.py` — Python reference implementation of the whole game loop plus automatic
  players; `sim/results/` holds the latest batch. The TypeScript engine must reproduce it 1:1.
- `sim/build_gdd.py` + `sim/gdd_template.md` — regenerate `docs/GDD.md` from the simulator data.
- `ALPHA-PROMPT.md` — the kickoff brief for the alpha build (scope, stack, phases, acceptance criteria).
- `assets/art/` — generated art (see below). `tools/jobs/` — image batch job files (kept in git).

## Engineering rules
- Engine in `src/engine/` is pure and deterministic (seedable RNG inside the state); no React/DOM imports.
- One command → `applica(stato, comando)` → new state + list of outcomes to display.
- Game texts live in `src/data/testi.ts`.
- UI shows words, icons and colours; numbers only behind the `(?)` tooltip (GDD §Interfaccia).
- Balancing changes go to `sim/maranza_sim.py` → `python3 sim/export_data.py` → `python3 sim/build_gdd.py`.
- Before shipping engine changes run `scripts/autoplay.ts` and compare with `sim/results/batch_finale.txt`.

## Image generation
Use the `generate-image` skill (`.claude/skills/generate-image/SKILL.md`; if missing, copy it from
`tools/_install-skill/generate-image/`) for any sprite, icon, background or concept art. It wraps
`tools/gen-image.mjs` (OpenAI gpt-image). Requires `OPENAI_API_KEY` in `.env` (see `.env.example`).
Art direction lives in `tools/image-style.md` and is auto-prepended to every prompt.
Satire guardrails: caricature of behaviours and outfits, never ethnic or religious mockery; no real
brands, people or crests; no text inside images.
